How It Works
Simple & Transparent
The module integrates directly into Odoo's export pipeline without modifying core logic.
1
User starts XLSX export
Select records from any list view and export as Excel normally.
2
Configured models are checked
The system reads your configured models from Odoo General Settings.
3
Branding is injected
Company logo, metadata, and styled headers are automatically added.
4
Excel downloads instantly
Users receive a fully branded professional spreadsheet.
