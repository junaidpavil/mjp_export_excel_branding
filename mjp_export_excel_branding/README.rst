# MJP Export Excel Branding

An Odoo 18 module that adds a branded company header to Excel exports for selected models, configurable directly from General Settings.

---

## Features

- Adds a **custom branded header** to exported `.xlsx` files containing:
  - Company logo
  - Company name
  - Generated by (user name + date & time)
  - Total selected record count
  - Styled column headers with blue background
- Works for both **flat exports** and **grouped exports**
- **Configurable from General Settings** — no hardcoding required
- Falls back to Odoo's default export for models not selected

---

## Requirements

- Odoo **18.0**
- Python dependencies: none (uses Odoo's built-in `xlsxwriter`)
- Depends on: `base`, `base_setup`,

---

## Installation

1. Copy the `mjp_export_excel_branding` folder into your Odoo `custom_addons` directory.
2. Restart the Odoo server.
3. Go to **Apps**, search for `Excel Export with Company Branding`, and click **Install**.

---

## Configuration

1. Go to **Settings → General Settings**.
2. Scroll to the **Excel Export Settings** section.
3. In the **Custom Layout Models** field, select the models you want the branded header applied to (e.g. `Sales Order`, `Invoice`).
4. Click **Save**.

> The selection is stored in Odoo's system parameters (`ir.config_parameter`) under the key `excel_export.custom_layout_models`.

---

## How It Works

```
User clicks Export → Excel (.xlsx)
        │
        ▼
Controller checks if model is in configured list
        │
        ├── YES → CustomExportXlsxWriter
        │             └── Adds branded header (logo, company, meta, styled columns)
        │                 Data starts from row 4
        │
        └── NO  → Default Odoo ExportXlsxWriter
                      └── Standard export, no changes
```

### Excel Header Layout

| Row | Content                                      |
|-----|----------------------------------------------|
| 0   | Company Logo + Company Name                  |
| 1   | Generated by `[User]` on `[DD-MM-YYYY HH:MM:SS]` |
| 2   | Total selected records count: `[N]`          |
| 3   | Column Headers (bold, blue background)       |
| 4+  | Data rows                                    |

## Technical Notes

- **`ExportLayoutXlsxMixin`** — Core mixin injected into both `ExportXlsxWriter` (flat) and `GroupExportXlsxWriter` (grouped) via `CustomExportXlsxWriter` and `CustomGroupExportXlsxWriter`.
- **`_get_custom_layout_models()`** — Helper function in the controller that reads `ir.config_parameter` on every export call to get the live list of configured models.
- **`res.config.settings`** — Extended with a `Many2many` field (`ir.model`) backed by an explicit relation table `excel_export_config_model_rel`. Values are serialized as a comma-separated string in `ir.config_parameter`.
- Freeze panes are applied at row 4 so headers remain visible while scrolling.
